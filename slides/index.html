PHP 標記

只有 <?php 和 ?> 之間的程式碼會被執行，標籤外的內容會被忽略。

<?php
echo "Hello world\n";

// 腳本在這裡結束，沒有寫 PHP 結束標籤

Hello world
  • <?php 後面必須接空白字元（空格、tab 或換行）[S1.1]
  • <?= 是 <?php echo 的簡寫 [S1.1]
  • 短標籤 <? 可能被停用，建議用 <?php ?> 和 <?= ?> [S1.1]
  • 純 PHP 檔最好刪掉結尾的 ?>，避免多出空白或換行 [S1.1]
出處：[S1.1][S1.3]

?> 的副作用

?> 隱含一個分號，而且緊接著的那一個換行不會輸出。

<?php echo "Some text"; ?>
No newline
<?= "But newline now" ?>

Some textNo newline
But newline now
  • 標籤外的內容會原樣輸出，但緊接在 ?> 後的換行不會輸出，所以 Some text 和 No newline 黏在一起 [S1.2][S1.3]
  • 每個語句用分號結束；程式碼段最後一行可以省略分號 [S1.3]
  • 註解有 //、#、/* */ 三種 [S1.4]
  • 單行註解遇到 ?> 就結束，後面的 HTML 會被輸出 [S1.4]
出處：[S1.2][S1.3][S1.4]

動態型別

變數不用宣告型別，型別由目前存放的值決定。

<?php
$v = "foo";
echo get_debug_type($v), "\n";
$v = 12;
echo get_debug_type($v), "\n";
var_dump(is_int($v));

string
int
bool(true)
  • 內建型別：null、bool、int、float、string、array、object、callable、resource [S2.1]
  • 同一個變數先放 string 再放 int，型別會跟著變，不會報錯 [S2.9]
  • var_dump() 看值和型別，get_debug_type() 取得型別，is_int() 這類函式檢查型別 [S2.1]
出處：[S2.1][S2.9]

真假值

轉成 bool 時是 false 的值只有少數幾個，其中 "0" 要特別小心。

<?php
var_dump((bool) "0");
var_dump((bool) "false");
var_dump((bool) -1);
var_dump((bool) array());
var_dump((bool) array(12));

bool(false)
bool(true)
bool(true)
bool(false)
bool(true)
  • false 的值：false、0、0.0、""、"0"、空陣列、null [S2.4]
  • 其他所有值都是 true，包括 -1 和 "false" [S2.4]
  • 所以 if ($x == TRUE) 不必要，直接寫 if ($x) [S2.4]
出處：[S2.4]

整數與浮點數

八進位前綴是 0、溢位會變 float、沒有整數除法運算子。

<?php
var_dump(0123);
var_dump(PHP_INT_MAX + 1);
var_dump(25/7);
var_dump(intdiv(25, 7));
var_dump(floor((0.1+0.7)*10));

int(83)
float(9.223372036854776E+18)
float(3.5714285714285716)
int(3)
float(7)
  • 0123 是八進位的 83，不是 123 [S2.5]
  • 超出 int 範圍會變成 float；PHP 不支援無號 int [S2.5]
  • 沒有整數除法運算子，要用 intdiv() [S2.5]
  • float 有精度問題，floor((0.1+0.7)*10) 是 7 不是 8；比較時用 epsilon [S2.6]
出處：[S2.5][S2.6]

字串

單引號不插值、雙引號才插值；連接字串用 .，不是 +。

<?php
$name = 'PHP';
$arr = ['fruit' => 'banana'];
echo 'Hello $name\n', PHP_EOL;
echo "Hello $name\n";
echo "1" + "1", PHP_EOL;
echo "1" . "1", PHP_EOL;
echo "This works: {$arr['fruit']}", PHP_EOL;

Hello $name\n
Hello PHP
2
11
This works: banana
  • 單引號只處理 \' 和 \\，\n 和變數都不會被代入 [S2.7]
  • 字串是位元組陣列，$str[0] 依位元組存取，對多位元組字元集不安全 [S2.7]
  • 帶引號的鍵要用 {$arr['fruit']}；"$arr['fruit']" 是解析錯誤 [S2.8]
  • 多行文字可用 heredoc（<<<EOT）和 nowdoc [S2.7]
出處：[S2.7][S2.8]

陣列

PHP 的 array 其實是有序映射，可以當 list、字典、堆疊、佇列用。

<?php
$a = array(1 => 'one', 2 => 'two', 3 => 'three');
unset($a[2]);
$a[] = 'four';
print_r($a);
$arr1 = array(2, 3);
$arr2 = $arr1;
$arr2[] = 4;
echo count($arr1), " ", count($arr2), PHP_EOL;

Array
(
    [1] => one
    [3] => three
    [4] => four
)
2 3
  • key 可以是 int 或 string，同一個 array 可以混用 [S2.8]
  • $arr[] = value 附加；沒指定 key 時用最大 int key 加 1 [S2.8]
  • unset() 不重建索引，需要的話用 array_values() [S2.8]
  • array 的指派會複製值，要共用要用 & [S2.8]
出處：[S2.8]

型別轉換與比較

PHP 依「上下文」自動轉型；比較要分清楚 == 和 ===。

<?php
var_dump("5" + 3);
var_dump(5 + 1.5);
var_dump(5 . 3);
var_dump(1 == "1", 1 === "1");

int(8)
float(6.5)
string(2) "53"
bool(true)
bool(false)
  • 上下文有：數字、字串、邏輯、整數和字串、比較、函式 [S2.9]
  • 算術有 float 運算元時結果是 float，否則是 int [S2.9]
  • 強制轉型寫 (int)、(string) 等，僅影響這次運算，變數型別不變 [S2.9]
  • == 只比較值；=== 值和型別都要相同 [S5.1]
出處：[S2.9][S5.1]

變數：傳值與引用

變數以 $ 開頭、名稱區分大小寫；指派預設是複製值，加 & 就變成引用。

<?php
$var = 'Bob';
$Var = 'Joe';
echo "$var, $Var", PHP_EOL;

$foo = 'Bob';
$bar = $foo;
$bar = 'Alice';
echo $foo, PHP_EOL;
$ref = &$foo;
$ref = "My name is $ref";
echo $foo, PHP_EOL;

Bob, Joe
Bob
My name is Bob
  • $var 和 $Var 是兩個不同的變數 [S3.1]
  • 名稱以字母或底線開頭，$4site 是非法的 [S3.1]
  • 引用讓新變數成為別名，改任一個都會影響另一個 [S3.1]
  • 存取未定義的變數只會發出 E_WARNING 並得到 null [S3.1]
出處：[S3.1]

作用域

和 C 不同：函式裡看不到外面的全域變數，要用 global 宣告。

<?php
$a = 1;
function bad() { echo $a; }
bad();
function good() { global $a; echo $a, PHP_EOL; }
good();

Warning: Undefined variable $a in example.php on line 3
1
  • 只有函式作用域和全域作用域 [S3.2]
  • 在函式裡直接用全域變數，會被當成未定義的區域變數 [S3.2]
  • 也可以用 $GLOBALS['a'] 存取全域變數 [S3.2]
  • 超全域變數（例如 $_POST）在每個作用域自動可用 [S3.2][S3.4]
  • static 變數離開函式時值不會遺失 [S3.2]
出處：[S3.2][S3.4]

常數

用 const 或 define() 定義，使用時不加 $。

<?php
const GREETING = 'Hello World';
define('ANIMALS', array('dog', 'cat', 'bird'));

function show() { echo GREETING, " / ", ANIMALS[1], PHP_EOL; }
show();
try { echo Greeting; }
catch (Error $e) { echo get_class($e), ': ', $e->getMessage(), PHP_EOL; }

Hello World / cat
Error: Undefined constant "Greeting"
  • 常數在任何作用域都能存取，定義後不能修改或取消 [S4.1]
  • const 不能用在函式、迴圈、if 裡，這時改用 define() [S4.1]
  • 名稱區分大小寫；使用未定義的常數會丟出 Error [S4.1]
  • 魔術常數如 __LINE__、__FILE__、__DIR__ 的值依使用位置而變 [S4.2]
出處：[S4.1][S4.2]

常見陷阱總整理

八個「換成 PHP 就會踩」的地方。

真假值"0" 是 false，"false" 是 true [S2.4]
字串連接用 .，+ 沒有這個功能 [S2.7]
八進位0123 是 83，不是 123 [S2.5]
浮點數不要直接比較相等，用 epsilon [S2.6]
陣列unset() 不重建索引；指派會複製 [S2.8]
結束標籤?> 後的換行不會輸出 [S1.3]
作用域函式看不到全域變數，要 global [S3.2]
常數const 不能放在函式或 if 裡 [S4.1]

小測驗

先想一想，再點開看答案。

Q1：var_dump((bool) "0"); 會印出什麼？

bool(false)，字串 "0" 轉成 bool 是 false [S2.4]

Q2：echo "1" + "1"; 和 echo "1" . "1"; 各印出什麼？

2 和 11；+ 是算術，. 是字串連接 [S2.7]

Q3：函式裡直接 echo $a;（$a 定義在函式外）會怎樣？

得到未定義變數的警告，結果是 null；要先宣告 global $a; [S3.2]
