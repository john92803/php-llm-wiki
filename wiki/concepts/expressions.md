## 一句話說明
PHP 是表達式導向的語言，表達式就是「任何有值的東西」[S5.1]。

## 說明
最基本的表達式是常數和變數；函式呼叫也是表達式，值是它的回傳值 [S5.1]。

指派語句本身也是表達式，值是被指派的值；所以 `$b = ($a = 5)` 等於 `$a = 5; $b = 5;` [S5.1]。指派的順序是由右到左，所以也可以寫成 `$b = $a = 5` [S5.1]。

前遞增 `++$variable` 的值是遞增後的值；後遞增 `$variable++` 的值是遞增前的原始值；兩者對變數的影響相同 [S5.1]。

比較表達式的值是 `false` 或 `true` [S5.1]。PHP 支援 `>`、`>=`、`==`、`!=`、`<`、`<=`，以及全等運算子 `===`（值和型別都相同）和非全等運算子 `!==`（值或型別不同）[S5.1]。使用比較運算子時會發生型別轉換，規則見手冊的型別比較表 [S2.9]。

複合指派：`$a += 3` 表示取 `$a` 的值加 3 再指派回 `$a`；任何二元運算子都可以這樣用，例如 `$a -= 5`、`$b *= 7` [S5.1]。`$a += 3` 這個表達式的值是指派後的值 [S5.1]。

三元條件運算子 `$first ? $second : $third`：第一個子表達式為 `true` 時，值是第二個子表達式，否則是第三個 [S5.1]。

一條語句是「表達式加分號」[S5.1]。在條件和迴圈中，表達式會在必要時自動轉換為布林值 [S5.1]。

## 範例
```php
<?php
function double($i)
{
    return $i*2;
}
$b = $a = 5;        /* 把 5 指派給 $a 和 $b */
$c = $a++;          /* 後遞增：$c 拿到 $a 原本的值 5 */
$e = $d = ++$b;     /* 前遞增：$d、$e 拿到 $b 遞增後的值 6 */
$f = double($d++);  /* 2*6 = 12 */
$g = double(++$e);  /* 2*7 = 14 */
$h = $g += 10;      /* $g 變成 24，$h 也是 24 */
echo "$a $b $c $d $e $f $g $h", PHP_EOL;

var_dump(1 == "1", 1 === "1");
?>
```
輸出（PHP 8.3.6 實測）：
```text
6 6 5 7 7 12 24 24
bool(true)
bool(false)
```

## 常見陷阱
- `$c = $a++` 的 `$c` 拿到的是遞增前的值 [S5.1]
- `==` 只比較值，`1 == "1"` 是 true；要連型別一起比較用 `===` [S5.1]
