## 摘要
PHP 程式碼寫在 `<?php` 和 `?>` 之間，標籤外的內容會被 PHP 解析器忽略、原樣輸出，所以 PHP 檔可以直接混在 HTML 裡 [S1.1][S1.2]。語句用分號結尾，但結束標籤隱含一個分號 [S1.3]。註解有 `//`、`#`、`/* */` 三種 [S1.4]。

## 重點
- `<?php` 之後必須接一個空白字元（空格、tab 或換行），否則是語法錯誤 [S1.1]
- `<?=` 是 `<?php echo` 的簡寫；短標籤 `<?` 可以被 `short_open_tag` 停用，建議用 `<?php ?>` 和 `<?= ?>` [S1.1]
- 檔案只有 PHP 程式碼時，最好省略結尾的 `?>`，避免意外輸出空白 [S1.1][S1.3]
- 結束標籤會吃掉緊接在後面的一個換行 [S1.3]
- 單行註解遇到 `?>` 就結束；`/* */` 不能巢狀 [S1.4]

## 跟其他語言不同的地方
- 檔案不是「全部都是程式碼」：標籤外的文字會直接輸出 [S1.2]
- 結束標籤 `?>` 本身就代表一個分號，最後一行可以不寫分號 [S1.3]
- 除了 C 風格的 `//`、`/* */`，也可以用 shell 風格的 `#` [S1.4]
